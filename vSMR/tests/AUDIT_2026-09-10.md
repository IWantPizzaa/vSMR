# Audit disposition — 10 September 2026

The supplied audit describes `4af57c0`. These changes were checked against the
working tree based on `ef37e23`. The entries below distinguish concrete fixes
from recommendations that did not identify incorrect behavior.

| Finding | Resolution |
| --- | --- |
| Q1 — large functions | Tag definition resolution, compilation and evaluation were extracted into `tags/CompiledTagDefinition.*` and are tested independently. Function length alone does not establish a bug. The remaining large normalization, menu and AVISO functions have not been rewritten solely to meet a line-count target. |
| Q2 — namespace pollution | Removed `using namespace std` from application headers and qualified the affected declarations and uses. |
| Q3 — ignored validator results | Added `[[nodiscard]]` to updater URL, signature, hashing, package, path and inbound-message predicates. Builds treat compiler warnings as errors. |
| Q4 — manual resource cleanup | Both HTTP clients share a noncopyable WinHTTP handle owner. SHA-256 uses an owning digest object; both `goto cleanup` paths were removed. |
| Q5 — development checks | Shared build properties enforce `/W4 /WX`, `/permissive-`, CFG and `/Qspectre`. Debug is now selectable in the solution. CI runs MSVC code analysis and the JSON fuzz smoke test under AddressSanitizer. The fuzz entry point is also compatible with libFuzzer. |
| Q6 — avoidable copies and modernization | SDK tag inputs are const references; output fills reusable token storage. Cosmetic randomness uses a private `<random>` engine. Refresh logging is a function with consistent argument evaluation. New regressions exercise JSON limits, URL policy, font-cache behavior, tag compilation and hashing. |
| S1 — old RapidJSON | Replaced the 0.11 subset with the complete upstream headers pinned to `24b5e7a8b27f42fa16b96fc70aade9106cf7102f`. Recorded source, commit, archive hash and license in `data/Licenses/DEPENDENCIES.md`. |
| S2 — unguarded parsing | Every production DOM parse now uses `shared/JsonDocument.hpp`. Both SAX and DOM passes use iterative parsing and validate UTF-8. Resource limits are checked before DOM allocation. A source check prevents new direct parse sites. |
| S3 — wildcard download hosts | Removed the `githubusercontent.com` suffix wildcard. Only explicitly named GitHub release/API hosts are accepted. Tests reject raw and arbitrary user-content subdomains. |
| S4 — revocation | The Authenticode bootstrap now requests certificate-chain revocation checking and fails closed when trust cannot be established. The configured signer pin continues to bypass bootstrap discovery. |
| S5 — TLS/port policy | Both clients require TLS 1.2 or newer and HTTPS port 443. TLS 1.3 is enabled when supported; failure to configure the TLS policy aborts the request. |
| S6 — NUL truncation | The common parser rejects embedded NUL bytes and parses the complete byte span. Signed manifests and unsigned release responses cannot silently accept a prefix. |
| S7 — binary hardening | Added compiler and linker CFG, compiler Spectre mitigations and conformance checking across runtime, loader, crash handler and tests. `/CETCOMPAT` is x64-only and does not apply to this x86 plug-in. |
| S8 — noted designs | The Hoppie query format is required by its API; existing HTTPS and log redaction remain. The per-user extraction script does not cross a privilege boundary. Neither observation establishes an additional bug. |
| P1 — tag model cost | Compiled definitions and embedded color rules are cached until profile/tag edits invalidate them. Substitutions use precompiled text segments. Token values use contiguous storage reused with scene buffers. Live SDK/CDM values are still refreshed to keep displays current. Replacement values are no longer recursively interpreted as token names. |
| P2 — font caches | Main, AVISO and secondary-radar tag caches persist between frames. Font, DPI, rendering mode, page scale and transform changes invalidate measurements. Entry and string-size limits bound memory growth. No persistent cache holds a frame's Graphics pointer. |
| P3 — SDK timing | Detailed per-call clocks run only in verbose diagnostics mode; normal refreshes still record inexpensive stage totals and call counts. |
| P4 — brush allocations | A bounded brush palette is reused throughout each tag/target pass, including trails and alert bands. |
| P5 — callback overhead | Projection and visibility callbacks use a non-owning function pointer plus context. Named callables outlive their render pass; temporary callables cannot bind. This removes owning `std::function` machinery without claiming the SDK projection itself can inline. |
| P6 — logging allocation | The per-target icon trace accepts `const char*`; formatting happens after the verbose check. |
| P7 — hot maps | Tag tokens use contiguous storage; target hit areas and callsign-keyed RIMCAS alerts use hash maps. Runway and countdown containers retain ordering. `AircraftOnRunway` was already an unordered set in the current source. |
| P8 — hover copy and function size | Hover text references the captured scene string directly. Function-size recommendations are covered by Q1; no frame-rate improvement is claimed without a EuroScope workload. |

## Verification

- Full Release build, including loader, runtime, crash handler and regression executable.
- Full Debug build of the loader, runtime and crash handler with `/W4 /WX` and CFG.
- Native regression suite, including the new audit cases.
- Generated JavaScript/CSS checks, stylesheet ownership checks and Edge browser regressions.
- All production JSON entry points checked for use of bounded validation.
- AddressSanitizer JSON smoke test: 10,012 seed and mutated inputs.
- MSVC `/analyze` Release build completed successfully. Analysis still reports warnings in existing code and an upstream RapidJSON union; this is not a claim of zero analyzer warnings. The new hashing warnings and HTTP nullable-field warnings were corrected, and inset rendering now rejects a missing radar/configuration/graphics context.
- Application changes pass `git diff --check`. Vendored headers match upstream byte for byte; upstream whitespace is preserved.

The two build-helper scripts already deleted in the supplied working tree were
left deleted. For verification, their committed versions were executed from a
temporary validation directory against the current sources.

No release was published. Host-level visual behavior and timing still require a
EuroScope session; the automated checks validate rendering behavior and cache
reuse using the regression harness.
